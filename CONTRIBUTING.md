# Contributing to StarryPocket

Thanks for helping Nova shine a little brighter.

## Ground Rules

- Be kind and constructive.
- Keep changes focused and include a short explanation of the user-visible result.
- Use English for code, comments, commit messages, issues, and pull requests.
- Run `python -m py_compile main.py` before submitting.
- Update screenshots when a UI change is visible.

## Privacy Rules

Never commit:

- Photos of real people
- Private desktop screenshots
- Personal names, email addresses, file paths, or account identifiers
- API keys, tokens, logs, or local settings
- Generated build directories

Use the original Nova artwork or create new privacy-safe demo artwork. If you need personal media while testing, place it in `private_photos/`, which is ignored by Git.

## Collaboration Policy

StarryPocket is owner-maintained. No third-party GitHub collaborators are added. Automated coding agents, including Cursor, are not listed as collaborators or commit co-authors.

External contributions are accepted as pull requests from contributors who agree to the project license.

## Pull Requests

1. Fork the repository.
2. Create a focused branch.
3. Avoid unrelated formatting churn.
4. Describe what changed, why it helps users, and how you tested it.
5. Confirm that no private data or personal media is included.
