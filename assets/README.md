# Nova Demo Artwork

All artwork in this directory is original demo material created for StarryPocket.
It does not depict or derive from a real person.

- `source/nova.svg` is the ready-to-open Aurora master illustration.
- `source/nova-template.svg` is the editable color template used by the renderer.
- `nova_aurora.png`, `nova_ember.png`, and `nova_mint.png` are renderer outputs.
- `icon.png` and `icon.ico` are application and tray icons.

Regenerate the PNG and ICO files with:

```powershell
python tools/render_demo_assets.py
```

The artwork is distributed under the repository's MIT license.

Do not add personal photos or images of real people to this directory.
